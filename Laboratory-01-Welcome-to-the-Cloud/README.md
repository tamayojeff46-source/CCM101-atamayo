# Laboratory Activity 1: Welcome to the Cloud

## Mission Overview
Onboarding mission to set up a cloud-based Linux environment, explore system hardware metrics, and initialize a Git portfolio.

## Objectives
- Access Linux playground via KillerCoda.
- Gather core system telemetry.
- Establish structured project repositories.

2. Inspected OS, Kernel, RAM, and Disk specifications.
3. Created workspace folders and technical documentation.
