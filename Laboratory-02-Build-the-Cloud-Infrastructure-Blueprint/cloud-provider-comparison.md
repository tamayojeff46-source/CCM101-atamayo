### Guide Questions & Answers

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
Amazon Web Services (AWS) offers the broadest range of services due to being the pioneer in public cloud infrastructure. It boasts the largest global market share, the most mature ecosystem of tools, and hundreds of specialized cloud offerings.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
Microsoft Azure is the best choice because it seamlessly integrates with Windows Server, Active Directory, Office 365, and Microsoft SQL Server. It also provides cost savings through Azure Hybrid Benefit for existing Microsoft software licenses.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**
Google Cloud Platform (GCP) is widely recognized for AI/ML and Kubernetes because Google originally created Kubernetes (Google Kubernetes Engine or GKE) and leads in AI research with tools tulad ng Vertex AI at custom TPUs.

**4. What similarities did you observe among the three cloud providers?**
All three providers follow the same fundamental architecture: they virtualize compute, storage, and networking into on-demand, pay-as-you-go services. Additionally, each provides granular Identity and Access Management (IAM) controls, region-based high availability, and web consoles with matching command-line interfaces.
