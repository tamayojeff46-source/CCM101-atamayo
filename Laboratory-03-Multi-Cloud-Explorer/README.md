## Overview
This laboratory activity focuses on exploring major public cloud providers—Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). It includes investigating core cloud infrastructure, evaluating platform capabilities, mapping equivalent cloud services, recommending architectures for real-world client scenarios, and continuing terminal investigations on Linux environments.
